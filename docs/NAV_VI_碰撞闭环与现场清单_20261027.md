# NAV／VI：货架碰撞、完整流程与现场交接

日期：2026-10-27。环境：WSL Ubuntu 24.04、ROS 2 Jazzy。

本轮目标是完成现有资料能支持的 NAV／VI 软件和仿真工作。没有录制新视频。
仿真结果针对下列明确的平面模型；实机测量、传感器校准和实体搬运验收仍需在现场完成。

## 1. 已补齐的软件流程

| 项目 | 本轮处理 |
|---|---|
| 未搬运的其他货架 | 每架有四根实体腿，激光能看到，车体碰撞计算会检查 |
| 载货外伸 | 车体与载货轮廓一起计算；被搬货架的台面不能穿过其他货架台面或墙 |
| 货架随车移动 | 抬起时记录真实相对偏移与角度；不会将货架瞬移到车中心 |
| 放下后的货架 | 在实际放下位置恢复四脚障碍物，后续路径和碰撞检查继续考虑 |
| 独立放置 | 四个独立位置，先后排再前排，不再共用一个终点目标 |
| 入架与退出 | Nav2 到接近点；扫码；低速对齐入架；抬起后退出；放下后空载退出 |
| 抬升判定 | 实际停车、位置与角度合格、没有接触，才返回模拟抬升完成 |
| 放置判定 | 检查分配位置、整架在终点区域、没有重叠、落腿不会压到车 |
| 完成计数 | 放下并完成退出后，才增加已完成数量 |
| 轮廓切换 | 两个 Nav2 代价地图均确认之后才能继续；载货包络包含允许的拾取偏差 |
| 扫码 | 真实二维码解码器；合成输入增加位置、朝向与数据新鲜度门槛 |
| 碰撞记录 | 分开记录实际接触、被仿真器挡住的碰撞指令、最小间距、每一步真实位姿 |
| 连续运动检查 | 包括平移、转向的中间扫掠，不只看离散帧的起点和终点 |
| 结果复核 | 任务结束后重放位姿日志，再检查货架状态转换、全部放置、扫掠间距与三分钟限制 |
| 运行中停车 | 原始控制指令、激光、轮速、IMU、融合里程计、TF 过期均停车；任务失联也停车 |
| 异常与人工停止 | ERROR 和 `/nav/emergency_stop` 锁定零速；不会自动放货或自动恢复 |
| 显示与使用入口 | 场地窗口显示真实货架位置、四脚、放置位和最小间距；新增检查命令和证据导出图 |

正常顺序为：

```text
START → Nav2 到货架接近点 → 识别完整货架码 → 低速入架
      → 停车/抬起/轮廓确认 → 载货退出 → Nav2 到独立放置位接近点
      → 低速对位 → END → 停车/放下/轮廓确认 → 空载退出
      → 下一架；第四架退出后 COMPLETE
```

保留旧回归场景与原有不带 docking 的任务模式。公共 EC 消息契约、EC 固件、原始 CAD 文件及子仓库指针没有修改。
新 docking 动作用标准 `NavigateToPose` 类型提供 NAV 内部的 `/dock_to_pose`，不要求 EC 增加新消息。

## 2. 已直接确定的开发基准

| 参数 | 本轮采用值与依据 |
|---|---|
| 场地与区域 | 内场 3020 × 2000 mm；起点与终点边界采用课程图 |
| 车体平面外包络 | CAD 给出的 282.502 × 286.568 mm，保留原始模型，不缩小车辆来让仿真通过 |
| 货架平面几何 | 140 mm 短边为图纸标注的开发基准；400 mm 长边为图上估算；15 mm 方腿为显式假设 |
| 货架位置 | 保留第 3 页带 A/B/C/D 标签示意图的估计位置；不冒充现场测量 |
| 抬升对齐门槛 | 平面中心偏差 ≤25 mm，角度偏差 ≤0.05 rad |
| 放置门槛 | 分配位置偏差 ≤40 mm，角度偏差 ≤0.08 rad；整架必须在终点区域且无重叠 |
| 接近/退出距离 | 420 mm；docking 直线速度上限 0.13 m/s，横向校正 0.04 m/s |
| 独立放置中心 | A=(220,610)、B=(220,1390)、C=(570,1390)、D=(570,610) mm，朝向均为 π |
| 地图与定位 | 仿真墙图 5 mm 分辨率；理想传感器对应 AMCL 参数仅写入本轮运行快照，未覆盖实机模板 |
| 碰撞通过门槛 | 实际接触=0；仿真器拦截碰撞指令=0；全程保守扫掠间距 >10 mm |
| 时限 | 从 START 到最后一架退出完成 <180 s，启动自检时间单独计算 |

抬起/放下只是通过几何约束的模拟执行器，不是接触力学。空载检查四脚、载货检查台面属于平面高度分类，
不能证明车体真实高度、升降行程、横梁和台面下沿之间有足够净空。

## 3. 验证与复现

最新完整检查证据目录：`output/rack-collision-20261027/final/`。
每轮运行目录保存源场景、生成地图、实际加载的几何/任务/导航参数、九次确认图片、事件和逐步位姿。
检查汇总见 [软件验证记录](NAV_VI_验证记录.md)；失败调试记录保留在相邻的 run01、run02 目录，没有混作通过结果。

```bash
cd '/mnt/e/研究生/sem1课程/7503/dase7503-group-project'
bash scripts/nav.sh build
bash scripts/nav.sh demo

# 无窗口复核，使用一个新的输出目录：
bash scripts/nav.sh check all /一个新的检查目录
# 可分别运行：
bash scripts/nav.sh check course
bash scripts/nav.sh check collision_stress
bash scripts/nav.sh check collision_faults
bash scripts/nav.sh check motion_safety
# 可选：需 Xvfb，完成整轮后只保存一张场地窗口截图，不录视频
bash scripts/nav.sh check viewer /一个新的界面检查目录
```

`collision_stress` 包含初始定位偏差、真实货架相对任务坐标偏差、更窄货架与更粗腿、重复正常运行。
`collision_faults` 在真实 Nav2/docking 运行时冻结激光或轮速时间戳，检查最终零速和真实仿真位置停止；
其中轮速故障在载货阶段注入，检查货物仍保留。另测人工停止、真实解码错码和空白图像。
还单独关闭载货行驶中的 `motion_guard` 进程，验证结束前发送零速、实际位置停止且不自动放货。
基础回归继续覆盖导航拒绝/失败/超时、升降无反馈、轮廓更新失败、任务时间耗尽、取消与扫码停止。

整套 launch 同时关闭时，任务端可能来不及收到 Nav2 的取消确认，日志会如实报告“cleanup unconfirmed”。
这不冒充成功应答：单任务取消已另测，最终速度进程退出前发送零速也已另测；主机崩溃或链路断开仍必须由 EC 独立看门狗处理。

单轮关键文件：

| 文件 | 用途 |
|---|---|
| `collision_summary.json` | 接触/拦截次数、最小间距、最终四架位置及每次取放 |
| `collision_trace.jsonl` | 每个运动步的时间、真实车位姿、速度、载货偏移与接触间距 |
| `collision_audit.json` | 事后轨迹重算结果、各阶段最小间距及任务时长 |
| `collision_paths.png` | `python3 scripts/plot_collision_run.py /该轮目录` 生成的四架轨迹图；需要 matplotlib |
| `qr/`、`qr_scan.csv` | 真实解码确认帧、完整内容、时间和来源 |

## 4. 现场只需补测、校准和执行验收的事项

| 现场事项 | 数据填写或检查位置 | 完成标准 |
|---|---|---|
| 实际 A/B/C/D 位姿、二维码完整后缀 | 测量后的 mission YAML：`rack_*`、`rack_qr_codes` | 坐标系一致；每个完整码唯一且对应正确货架 |
| 货架外尺寸、腿截面、内部净宽和下方净高 | 场景几何；实机 mechanical YAML 的 `loaded_bounds_mm` | 实车和货架全包络都有余量；不只量底盘板 |
| 空载/载货外伸、线缆和最高点 | `empty_bounds_mm`、`loaded_bounds_mm` | 包含所有突出部分；载货轮廓完整包住空载轮廓 |
| CAD 高度与课设上限 | CAD 当前姿态约223.04 mm，课设上限180 mm | 测实车降下后的最高点；若仍超限，需机械调整，软件无法消除 |
| 雷达测量中心、相机光心、IMU 轴向 | mechanical YAML 的传感器 xyz/rpy | 真实 TF、扫描方向、角速度符号和图像方向正确 |
| 实际相机与雷达驱动 | 已有传感器/视觉启动入口 | 实时图像和扫描稳定、时间戳正确、没有遮挡盲区导致漏检 |
| 刹停距离、轮滑、速度/加速度与定位误差 | Nav2/控制参数、现场记录 | 载货和空载均能在安全余量内停止；不使用仿真理想参数冒充标定 |
| 升降完成、最低/最高位置与载重 | 已有 EC 适配与现场观察 | 确认真实到位依据；当前适配的人工观察确认不能冒充自动到位传感器 |
| EC 串口/桥接和丢包停车 | 已有 EC 适配、独立看门狗 | 实际连接、断线、停机、保持货物均正确；本机未运行未提供的私有桥接源码 |
| 四个最终放置位与通道 | 测量后的 `placement_*`、`docking_distance_m` | 每架全部在终点区，互不重叠；最后仍能退出 |
| 最终验收 | 真实三分钟任务与异常停车记录 | 四架实体搬运、途中不落地、无碰撞、六类二维码截图与日志齐全 |

这些是现场物理确认，不再要求 CAD/EC 重填已给过的表，也不接手接口表排除的 B6–B10、B21 底层实现。
软件入口和测试已为这些现场操作准备好；未将尚未发生的实物结果标为通过。
