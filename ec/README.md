# 电控代码

`firmware/` 是指向 [7503esp32](https://github.com/CaspianW/7503esp32) 的 Git submodule，
当前固定在提交 `2b56582`，源码入口为 `firmware/7503esp32/7503esp32.ino`。

首次获取代码：

```bash
git clone --recurse-submodules https://github.com/zwkcyy/dase7503-group-project.git
```

已经克隆公共仓库的用户可运行：

```bash
git submodule update --init ec/firmware
```

上游固件仓库目前是私有的。只有获得该仓库读取权限的用户才能初始化子模块；
公共仓库只保存仓库地址和固定提交号，不包含固件文件。电控负责人更新私有仓库后，
还需要更新公共仓库中的子模块提交号。

## 固件版本与通信说明（2026-11-05）

本目录的 Git submodule 仍固定在历史提交 `2b56582`。早期记录提到的 ASCII
串口键盘指令及电机、编码器、轮速闭环、升降测试，属于当时的交付说明，
不能用于判断当前实板的协议或代表本次真机验收通过。

当前 NAV 使用 [`ec_serial_bridge`](../ros2_ws/src/common/ec_serial_bridge/README.md)
对接二进制 UART 协议；桥的协议实现依据 EC 仓 `6985c8a` 的通信文档与源码。
**协议参考提交、主仓固定的子模块提交、实际烧录的固件版本是三项不同的记录。**
截至本次检查，未取得实板固件的版本标识，因此不能声称实板烧录的是 `6985c8a`。
这条 NAV 接入链路使用 ROS 2 ↔ 串口桥，不使用 micro-ROS Agent。

2026-11-05 已收到有效的实板二进制遥测及控制回执；一次悬空低速脉冲中，
EC 回报的轮里程计速度明显高于下发速度，后续电机测试已停止。
通信成功不等于轮速闭环、实际车速或四轮方向通过验收。现状及待 EC 核对项见
[树莓派实测记录](../docs/NAV_EC_树莓派实测记录_20261105.md)；本机详细证据保存在
`output/pi_full_validation_20261105/EC_速度异常排查_20261105.md`。

用户随后转述 EC 同学称 PWM 电机最低速度约 `0.31 m/s`，但测量方式未知：
尚不能区分落地实测、悬空轮速或参数换算。该口头信息未作为物理标定或根因确认。
现有差速 NAV 前进上限 `0.15 m/s`、入架 `+0.08/-0.06 m/s` 与 8 mm 到位目标
依赖低速可控性；不因该口头数值提高速度或放宽悬空保护。
